Uklana Restaurant App v1.8

Ringtone fix:
- Selected ringtone now creates a fresh Android notification channel.
- This avoids Android's immutable channel-sound limitation.
- Selected ringtone URI is retained where the provider allows it.
- Full-screen alert activity also plays the selected ringtone directly in a loop.

After installing this update, open Ringtone Settings, choose the ringtone again, and press Test Ringtone.
