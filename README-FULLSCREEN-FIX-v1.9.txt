Uklana Restaurant App v1.9

Fixes:
- Wakes the device briefly when a high-priority order data message arrives.
- Uses the app full-screen notification flow even while backgrounded.
- On Android 14+, prompts for the Full-screen notifications special permission.
- Must be used with API plugin v3.5.4 (data-only FCM payload).

After installing:
1. Open the app once.
2. Allow Notifications.
3. Allow Full-screen notifications when prompted.
4. In phone battery settings, set the app to Unrestricted / No restrictions if the phone brand aggressively blocks background apps.
